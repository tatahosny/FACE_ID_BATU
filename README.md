# 🏛️ BATU FACE ID Registration & Queue Management System
### نظام تسجيل البصمة وإدارة طوابير طلاب الفرقة الثانية - جامعة برج العرب التكنولوجية (BATU)

نظام متكامل، آمن وعالي الاعتمادية مخصص لإدارة تسجيل البصمة وتنسيق طوابير الانتظار لطلاب الفرقة الثانية بقسم تكنولوجيا المعلومات بجامعة برج العرب التكنولوجية، مجهز بالربط الكامل مع قاعدة بيانات **Neon PostgreSQL** وبوت **Telegram**.

---

## 🚀 المميزات الرئيسية (Core Features)

1. **إدارة الهيكل الأكاديمي الشامل (Academic Hierarchy)**:
   - 3 مجموعات رئيسية (`G1`, `G2`, `G3`).
   - 12 سكشن مخصص (`SEC-01` إلى `SEC-12`)، بمعدل 4 سكاشن لكل مجموعة.
   - قيود قاعدة بيانات صارمة تمنع ازدواجية تسجيل الطالب أو تعارض السكاشن والمجموعات.

2. **أمان وحماية البيانات الحساسة (Zero-Knowledge Architecture)**:
   - **الرقم القومي المصري (14 رقماً)**: مشفر كلياً بنظام التشفير المتماثل فائق الأمان **AES-256-GCM** مع مفتاح فريد و IV عشوائي لكل عملية حفظ.
   - **بحث بدون كشف الهوية**: يتم إنشاء بصمة تجزئة معمّاة باستخدام **HMAC-SHA256** مع ملح سري (`SECRET`) للتحقق من عدم تكرار الرقم القومي والبحث المشفر دون فك التشفير.
   - حماية تامة ضد تسريب الأرقام القومية: محجوبة بالكامل من واجهات العرض (UI)، وتيليجرام، والسجلات (Logs)، واستعلامات الموظفين.

3. **نظام حجز وتوزيع طوابير مانع للتضارب (Concurrency-Safe Queue Allocation)**:
   - إقفال الصفوف على مستوى قاعدة البيانات باستخدام `SELECT ... FOR UPDATE`.
   - قيد فريد يمنع تكرار رقم الدور لنفس الفترة `(booking_window_id, queue_number)`.
   - منع الحجز المزدوج للطالب لنفس الفترة مع ضمان القابلية للتكرار (Idempotency).
   - التحقق الفوري من سعة الفترة الأكاديمية والجدول الزمني.

4. **تكامل متقدم مع تيليجرام (Telegram Bot Integration & Idempotency)**:
   - البوت المعتمد: `@batu_face_id_bot`.
   - ربط آمن عبر رمز عميق أحادي الاستخدام (Deep Link Token) صالح لمدة 15 دقيقة فقط.
   - معالجة Webhook مع ضمان عدم تكرار التنفيذ (Idempotency) بناءً على `update_id`.
   - إرسال إشعارات الاقتراب (قبل 10 أدوار، وقبل 5 أدوار) وإشعار الاستدعاء وإشعار نجاح تفعيل البصمة.

5. **صندوق الإشعارات الموثوق (Durable Outbox Queue)**:
   - جدول `notification_outbox` لتفادي فقدان الإشعارات أثناء انقطاع الشبكة أو قيود Telegram Rate Limiting.
   - آلية إعادة المحاولة بانتظار تصاعدي (Exponential Backoff).
   - إمكانية تشغيل المعالجة يدوياً أو آلياً عبر API مجدول.

6. **لوحات تحكم وبوابات متخصصة (Role-Based Access Control)**:
   - **بوابة الطالب (`/`)**: التسجيل، ربط التيليجرام، التحقق من الأهلية، حجز الدور، ومتابعة شاشة الطابور المباشرة.
   - **بوابة الموظف (`/staff`)**: إدارة الطابور الحي، الاستدعاء المباشر، البحث الأكاديمي، وتفعيل البصمة مع تسجيل هوية الموظف وتاريخ العملية.
   - **لوحة تحكم المسؤول الفائق (`/admin`)**: إحصائيات حية، إدارة المجموعات، السكاشن، الفترات الزمنية، الموظفين، حملات البث الجماعي على تيليجرام، قوالب الرسائل، وسجلات المراقبة والتدقيق (Audit Logs).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الإطار البرمجي**: [Next.js 14](https://nextjs.org/) (App Router, React Server Components & Client Components)
- **لغة التطوير**: TypeScript (Strict Mode)
- **قاعدة البيانات**: PostgreSQL المستضافة على [Neon](https://neon.tech/) (Serverless with Connection Pooling)
- **مخطط ومحرك الاستعلامات**: [Drizzle ORM](https://orm.drizzle.team/)
- **التصميم والواجهات**: Tailwind CSS، خط Cairo العربي الرسمي، دعم كامل للاتجاه من اليمين إلى اليسار (RTL)
- **التشفير والحماية**: Web Crypto / Node.js Crypto (AES-256-GCM, HMAC-SHA256, Bcrypt)
- **الاختبارات**: [Vitest](https://vitest.dev/) مع دعم اختبارات الوحدات (Unit) واختبارات التكامل المباشرة (Integration) واختبارات محاكاة التزامن العالي (Load Testing).

## 🛡️ معايير الأمن السيبراني المطبقة (Security Specifications)

1. **حماية التكرار والاصطدام**: منع إنشاء حساب مكرر بالرقم القومي عبر جدول التجزئة الآمن، مع إخفاء أصل الرقم القومي حتى عن قواعد البيانات الداخلية.
2. **عزل الجلسات (HttpOnly Cookies)**: حفظ جلسات تسجيل الدخول في ملفات تعريف ارتباط مشفرة بـ JWT ولا يمكن الوصول إليها عبر JavaScript، مع تفعيل خاصية `SameSite=Strict`.
3. **تحديد معدل الطلبات (Rate Limiting)**: حماية مسارات الـ API الحساسة كالتسجيل والدخول والربط من هجمات الإغراق (DDoS / Brute Force).
4. **سجل التدقيق (Audit Logs)**: تسجيل موثق لكافة الإجراءات الإدارية، مثل تفعيل بصمة الطالب، تعديل مواعيد الفترات، وإرسال الرسائل الجماعية.
