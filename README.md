---

## 🌟 نظرة عامة (Overview)

منظومة إلكترونية متكاملة، فائقة الأمان والاعتمادية، مخصصة لإدارة وتنظيم عمليات تسجيل بصمة الوجه وتنسيق طوابير الحضور لطلاب الفرقة الثانية بقسم تكنولوجيا المعلومات في **جامعة برج العرب التكنولوجية**.

توفر المنظومة بيئة تشغيلية تفاعلية تعتمد على أحدث معايير الأمان وتوزيع الأدوار، وتنظيم حضور الطلاب بدقة لمنع التكدس، مع إرسال إشعارات فورية وتنبيهات ذكية لحظة بلحظة.

---

## ✨ المميزات الرئيسية للنظام (Core Features)

### 1. 🏢 الهيكل الأكاديمي والتحكم بالسكاشن الفرعية (Academic Structure)
- **المجموعات الدراسية**: تقسيم مركزي يغطي مجموعات الفرقة الثانية (`G1`, `G2`, `G3`).
- **السكاشن والأقسام الفرعية**: دعم متقدم للسكاشن الأكاديمية مع الفصل الدقيق بين الأقسام الفرعية (`قسم A` و `قسم B`).
- **ضوابط فتح الحجز الموجه**: إمكانية توجيه فتح فترة الحجز لسكشن محدد أو قسم فرعي مخصص (قسم A فقط، قسم B فقط، أو كلاهما معاً)، بحيث يقتصر الحجز فقط على الطلاب المستهدفين.

### 2. 📍 المقر المعتمد المتغير لإشعارات البصمة (Dynamic Activation Location)
- تحكم حصري للمشرف العام (**Super Admin**) في ضبط وتغيير «المقر المعتمد» للجان البصمة من لوحة الإعدادات المركزية.
- إدراج المقر المعتمد تلقائياً وبشكل ديناميكي في رسائل التهنئة والاعتماد الرسمية المرسلة للطالب فور تفعيل وتوثيق بصمته.
- معاينة حية وفورية لنص الرسالة وشكلها النهائي مباشرة أثناء تعديل المقر.

### 3. ⏱️ إدارة ومراقبة الطابور الحي المباشر (Live Queue Management)
- متابعة فورية لحركة الطلاب والانتظار وتسلسل الأدوار لحظياً.
- نداء إلكتروني مباشر وتأكيد الحضور وانتقال الحالات بسلاسة.
- آلية تأخير الطلاب غير الحاضرين (10 أدوار للخلف) لإتاحة الفرصة لباقي المنتظرين.
- زر معتمد لنهاية اليوم خاص بالمشرف العام لإعادة تعيين عداد التذاكر ليبدأ من رقم 1 لجميع سكاشن المنظومة لليوم التالي.

### 4. 🎓 دليل الطلاب وسجل حالة البصمة المركزي (Student Directory)
- كشف مركزي شامل لجميع طلاب الفرقة الثانية وتوثيق حالات اعتماد البصمة.
- بطاقات إحصائية تفاعلية تعرض: إجمالي الطلاب المسجلين، البصمات المعتمدة، قيد الانتظار، وإحصائيات مخصصة لكل موظف وتاريخ محدد.
- فلاتر متقدمة ومتعددة: تصفية حسب المجموعة، السكشن، القسم الفرعي (A/B)، حالة الاعتماد، الموظف الموثق، وتاريخ توثيق البصمة.
- تصدير رسمي لكشوف الطلاب بصيغة **Excel** بنظام الشيت المزدوج (شيت الكشف الكامل + شيت مستقل مخصص للمفعل عندهم البصمة).

### 5. 🛡️ نظام الصلاحيات الصارم والحماية المتقدمة (Strict RBAC)
- **مسؤول النظام العام (Super Admin)**:
  - صلاحيات كاملة لإدارة فترات الحجز، المجموعات، السكاشن الأكاديمية، والجداول الزمنية.
  - التحكم في تعيين وحذف الموظفين، وضبط إعدادات المقر والمنظومة العامة.
  - إمكانية التفعيل المباشر للبصمة، إلغاء الاعتماد وإعادة إتاحة الحجز، والحذف الفردي أو المجمّع للطلاب.
  - الاطلاع الكامل على سجل التدقيق الأمني (Audit Logs) وتصفير تذاكر الطابور.
- **موظف البصمة ولجان الحضور (Staff)**:
  - شاشة تشغيلية مركزة ومحمية بالكامل: تقتصر فقط على لوحة المؤشرات، شاشة الطابور الحي، ودليل الطلاب.
  - حجب 10 صفحات إدارية حساسة بالكامل من القائمة الجانبية مع نظام حماية وتحويل تلقائي للمسارات (Route Guards).
  - حظر إجراءات حذف الطلاب أو إلغاء البصمة أو الحذف المجمّع في دليل الطلاب وتعيينها كـ «صلاحية استعراض فقط».
  - حظر أزرار تصفير التذاكر في شاشات الطابور.
- **بوابة الطالب (Student Portal)**:
  - استعلام مباشر وسهل عن حالة الحجز ومواعيد الحضور وجدول المواعيد المعتمد.

### 6. 🔒 معايير الأمان والخصوصية (Security & Privacy)
- تشفير بيانات الهوية وحماية الأرقام القومية بأعلى تقنيات التشفير القياسي المعتمد.
- سجل تدقيق أمني غير قابل للتعديل يوثق كل إجراء إداري مع هوية المنفذ وتاريخه.
- حماية متقدمة ضد التكرار والاصطدام وتضارب الحجوزات المتزامنة.

## 🛠️ البنية التقنية (Technology Stack)

- **الواجهة الأمامية والخلفية**: [Next.js 14](https://nextjs.org/) (App Router & Server Actions)
- **لغة التطوير**: TypeScript (نمط صارم ومعياري)
- **قاعدة البيانات**: PostgreSQL سحابية مدعومة بمحرك تجميع الاتصالات (Connection Pooling)
- **مخطط ومحرك البيانات**: [Drizzle ORM](https://orm.drizzle.team/)
- **التصميم والواجهات**: Tailwind CSS مع خط عربي متناسق ودعم أصيل للغة العربية (RTL) والأوضاع الليلية التفاعلية
- **محرك الأيقونات والتنبيهات**: Lucide React

## 💻 متطلبات التشغيل المحلي (Getting Started)

### 1. تثبيت الحزم والمكتبات:
```bash
npm install
```

### 2. تجهيز ملف البيئة (`.env`):
قم بإنشاء ملف `.env` محلي يحتوي على متغيرات التكوين الخاصة ببيئة التشغيل (بيانات اتصال قاعدة البيانات والمفاتيح السرية للتطبيق).

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```

افتح المتصفح وتوجه إلى `http://localhost:3000` للوصول إلى واجهة المنظومة.

### 4. بناء نسخة الإنتاج:
```bash
npm run build
npm run start
```
